# 🎯 Student Specialization Platform

## 💡 Project Idea
A No-Code platform designed to help students better determine and navigate their academic and career specialization paths.

---

## 🛠️ How It Was Built
The project was built entirely without writing code through the following steps:
1. **Requirements & UX Planning:** Defined user needs and structured the content flow.
2. **Interface Design:** Built interactive and engaging UI using modern design tools.
3. **Logic & Data Setup:** Configured workflows and backend logic to deliver seamless guidance.
4. **Deployment:** Published and launched the platform for direct user access.
